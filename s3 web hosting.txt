
# Step 3: Enable Static Website Hosting

Navigation:

```text
Bucket
→ Properties
```


# Step 5: Configure Bucket Policy

Without permissions:

```text
403 Forbidden
```

will appear.

---

## Navigate

```text
Bucket
→ Permissions
→ Bucket Policy
→ Edit
```

Paste:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadAccess",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-static-website-777/*"
    }
  ]
}
```

Replace:

```text
my-static-website-777
```

with your bucket name.

Save.

---

Website is now publicly accessible.

# Hosting Using AWS CLI

## Create Bucket

```bash
aws s3 mb s3://my-static-website-777
```

---

## Upload Files

```bash
aws s3 cp index.html s3://my-static-website-777
```

Upload entire website:

```bash
aws s3 cp website/ s3://my-static-website-777 --recursive
```

---

## Enable Website Hosting

```bash
aws s3 website s3://my-static-website-777 \
--index-document index.html
```

---

## Apply Bucket Policy

```bash
aws s3api put-bucket-policy \
--bucket my-static-website-777 \
--policy file://policy.json
```

# Common Errors

## Error 1

```text
403 Forbidden
```

Reason:

```text
Bucket Policy Missing
```

Fix:

```text
Add Public Read Policy
```

# Viva Questions

## What is Amazon S3?

Amazon S3 (Simple Storage Service) is AWS object storage used to store files, images, videos, backups and static websites.

---

## What is Static Website Hosting?

Static Website Hosting allows an S3 bucket to serve HTML, CSS and JavaScript files as a website.

---

## Can S3 Host PHP or Node.js Applications?

No.

S3 can host only:

* HTML
* CSS
* JavaScript
* Images
* Static Assets

Dynamic applications require:

* EC2
* Elastic Beanstalk
* ECS
* Lambda

---

## Why Do We Disable Block Public Access?

To allow users on the internet to access website files stored in the bucket.

---

## What Permission Is Required?

```json
"s3:GetObject"
```

This permission allows visitors to read website files.

---

## What Is Bucket Policy?

A Bucket Policy is a JSON document that defines who can access bucket resources and what actions they can perform.

---

## Difference Between S3 Website Endpoint and Object URL

| Website Endpoint     | Object URL            |
| -------------------- | --------------------- |
| Hosts Website        | Direct File Access    |
| Supports index.html  | No Default Page       |
| Supports Error Pages | No Error Page Routing |
